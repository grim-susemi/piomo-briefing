# OMO 상황판 사용 안내

대화 여러 개의 상태를 브라우저 한 장으로 보고, 아무 창에서나 한 줄로 결정합니다.
비유: 대화마다 긴 편지를 읽는 대신, 게시판 한 장을 훑는 것.

## 1. 열기
1. 아무 OMO 대화창에서 `/brief` 를 칩니다.
2. 브라우저에 "OMO 상황판"이 열리고, 채팅에 `상황판: <경로>` 가 뜹니다.
3. 경로만 보고 싶으면 `/brief path` 를 칩니다.

페이지 파일 위치:
```
C:/Users/USER/.omo-stable-500/home/.omo/agent/briefing/state/index.html
```

## 2. 보는 법
- 왼쪽 목차 탭: **나를 기다림** (결정·막힘·질문), **진행 중**, **끝남**.
- 페이지가 새로 바뀌면 "새 내용 있음" 배지가 뜹니다. 눌러야 반영돼요 (읽던 자리가 튀지 않게).
- 칩(작은 꼬리표) 뜻:

| 칩 | 뜻 |
| --- | --- |
| 증거 있음 | 적어 둔 파일이 그때 내용 그대로 있음 (다시 실행해 본 건 아님) |
| 증거 바뀜 / 증거 사라짐 | 그 파일이 바뀌었거나 없어짐 |
| 보고만 됨 | 에이전트가 말만 함 |
| 미확인 | 확인한 사람도 증거도 없음 |
| 후보 / 실사용 적용 / 적용 해당 없음 | 실사용에 안 올림 / 올렸다고 기록함 / 올릴 게 없는 일 |
| 보고 없음 | 그 대화가 일은 했는데, 끝내면서 상황판 보고를 안 남김 |
| 오래됨 | 마지막 갱신(⏱)이 오래전 |

페이지 아래 "ℹ 표시 뜻" 을 누르면 증거·적용 표시의 설명이 나옵니다.

## 3. 답하는 법
1. 결정 카드의 번호와 선택지를 봅니다. 예: `#12` A/B, 추천 A.
2. 아무 대화창에서 칩니다:
```
/decide 12A 13B
```
3. 번호만 쓰면 추천안으로 답합니다. 예: `/decide 12`
4. 채팅에 `반영: #12 A, #13 B` 가 보이면 성공입니다.

틀린 번호나 이미 답한 번호가 하나라도 섞이면 **아무것도 적용 안 됩니다**.

카드의 전달 표시:

| 표시 | 뜻 |
| --- | --- |
| 대기: 작업이 끝나면 전달 | 그 대화가 일하는 중, 끝나면 받음 |
| 대기: 그 대화가 다시 열리면 전달 | 그 대화가 닫혀 있음 |
| 전달 중 | 보냈고 확인 기다림 |
| 전달됨 ⏱ | 그 대화가 받음 (시각 표시) |

## 4. 일시 끄기
- 끄기: `/brief off` → `브리핑 꺼짐: ...` 이 보입니다.
- 켜기: `/brief on` → `브리핑 켜짐: ...` 이 보입니다.

## 5. 완전 제거
```
node C:/Users/USER/orca/projects/piomo-briefing/scripts/install.mjs --agent-dir C:/Users/USER/.omo-stable-500/home/.omo/agent --uninstall
```
`removed ... (generations and state kept)` 가 보이면 끝. 또는 이 파일 하나를 지워도 됩니다:
```

```
먼저 확인만 하려면 끝에 `--dry-run` 을 붙이세요 (아무것도 안 씀).

## 6. 알아둘 것
- 설치 전부터 열려 있던 대화는 새로 열어야 상황판에 나타납니다.
- `/decide` 답은 계획 선택일 뿐, 설치·푸시·삭제 승인이 아닙니다.
- "보고 없음" 은 고장이 아닙니다. 그 대화가 일을 마쳤지만 상황판에 보고를 안 남겼다는 뜻입니다.

| 증상 | 뜻 | 할 일 |
| --- | --- | --- |
| `적용 안 함: ...` | 번호가 틀렸거나 이미 답함 | 카드 번호 다시 보고 다시 치기 |
| `파일 권한 오류 - 다시 시도` | 다른 창과 동시에 씀 | 같은 명령 한 번 더 |
| 대화가 안 보임 | 설치 전에 열린 대화 | 그 대화 새로 열기 |
